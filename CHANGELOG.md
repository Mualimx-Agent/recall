# Changelog – Recall

Alle nennenswerten Änderungen an Recall werden hier dokumentiert.

## [1.0.0] – 2026-07-09

### 🎉 Erste öffentliche Version

**Features:**
- SM-2 Spaced-Repetition-Algorithmus (Anki-kompatibel)
- 4 Demo-Decks inklusive: Englisch, Programmierung, Geschichte, Naturwissenschaft
- Eigene Decks erstellen (Icon + Farbe wählbar)
- Card-Flip-UI mit „Antwort zeigen"-Button
- 4-Button-Bewertung (Again / Hard / Good / Easy) mit Intervall-Vorschau
- Streak-Tracking (sanft, motivierend)
- Statistiken: Tages-Reviews, Genauigkeit, gelernte Karten
- Tagesziel-Slider (5-100 Karten/Tag)
- Onboarding (3 Seiten)
- Settings: Dark Mode, Sprache DE/EN, Haptik
- About-Screen mit Datenschutz-Erklärung
- 100% lokal, keine Cloud, keine Tracker
- Open Source (Apache 2.0)
- DE/EN lokalisiert
- Plattformen: Android, iOS, Web

**Technisch:**
- Flutter 3.44.2
- Provider (State Management)
- GoRouter (Navigation)
- Google Fonts (Inter)
- Material 3 Design
- In-Memory State (Persistenz in v1.1.0)

**Interne Compliance:**
- Zero-Data-Audit bestanden
- Halal-Bau-Standards eingehalten
- DSGVO-konform
